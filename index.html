MailMerge‑SVG

Mail-merge a CSV onto an SVG template — tile it into a laser-ready grid, print a full sheet of each label, or make one page per row (certificates, badges). All in your browser; nothing is uploaded.

Pick the sheet you will print on. Margins, gaps, columns and rows fill in from that layout. Editing any of them switches this to Custom and keeps the page size; choose Custom in the list to drop the sheet.

Gap sets both axes and Margin sets every side. Override one axis or side below. All values are millimetres.

Tip: one full sheet per label accepts a single-label SVG (the root <svg> is the label, with a physical width and height) or a tile group labelled inkscape:label="Nametag" (or Tile/Cell) with a cut outline labelled Border. Choose an Avery sheet above the margins and every cell is a copy of that row. Grid mode still needs the tile group. For individual mode any whole-page SVG works. Either way, put {{TOKEN}} placeholders in the artwork and CSV column names are matched to them automatically. For certificates, add a hidden Inkscape layer labelled Backdrop (e.g. an image of the pre-printed stock) to preview alignment — it's shown only on screen, never in downloads. Use the zoom controls (or Ctrl/⌘ + scroll over the preview) to inspect detail; Fit resets to the full view. Host this file free on GitHub Pages, a gist (via htmlpreview), or anywhere static.
